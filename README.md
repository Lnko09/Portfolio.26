# Lurline Nkonde: Portfolio

My personal portfolio website, showing who I am, my skills and the projects I've built.

**Live site:** add your Netlify or custom domain link here

## Sections
- **Hero:** introduction and links to GitHub and LinkedIn
- **About:** my law background, customer support experience and creative work
- **Skills:** HTML, CSS, JavaScript, responsive design, Git and soft skills
- **Projects:** Taskflow, Evenly, Ember & Oat Café and more
- **Contact:** a clear call to action for recruiters and teams

## Features
- Fully responsive, from phones to large screens
- Automatic light and dark mode
- Sticky navigation with smooth scrolling
- Animated skill bars and scroll reveal effects, with reduced-motion support
- Profile photo slot: add `me.jpg` to the repository root

## Built with
HTML5, CSS3 (Grid, Flexbox, custom properties) and vanilla JavaScript.

## Deployment
Hosted on Netlify. Pushing changes to the `main` branch redeploys the site.
